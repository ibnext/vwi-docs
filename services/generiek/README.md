# Generieke bouwblokken

Deze map bevat generieke bouwblokken die gebruikt worden binnen de aangeboden services. Deze bouwblokken functioneren als herbruikbare componenten die door verschillende services kunnen worden ingezet.

**Belangrijk:** De generieke bouwblokken zijn niet direct beschikbaar in het portaal noch via de API. Ze worden intern gebruikt door de services om specifieke functionaliteiten te implementeren.

Per generiek bouwblok is een README.md bestand aanwezig met uitleg over de werking van het bouwblok en hoe deze gebruikt kan worden.
